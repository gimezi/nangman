# 파티 복사 형식 변경 설계

## 목표

파티 확인 화면에서 관리자가 파티 카드를 눌렀을 때 복사되는 문자열을 간결하게 만든다.

## 형식

- 팀 이름은 표시 이름의 첫 글자만 사용한다. 예: `홍팀`은 `홍`, `청팀`은 `청`.
- 첫 글자 바로 뒤에 1부터 시작하는 파티 번호를 붙인다.
- 파티 식별자와 캐릭터 목록 사이는 `-`로 구분한다.
- 캐릭터 닉네임 사이는 공백 없는 `/`로 구분한다.
- 예시: `홍1-이름1/이름2`, `청2-이름3/이름4`.
- 빈 파티는 `홍1-`처럼 복사한다.

## 범위

- 복사되는 문자열만 변경한다.
- 화면의 팀 및 파티 표시와 복사 완료 알림은 기존 형식을 유지한다.
- Clipboard API와 textarea fallback 모두 같은 문자열을 사용한다.

## 구현 및 테스트

복사 문자열 생성을 순수 함수로 분리하고, 홍팀과 청팀 예시, 공백 없는 구분자, 빈 파티 결과를 단위 테스트한다. 컴포넌트 클릭 핸들러는 이 함수를 호출한다.
